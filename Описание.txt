Описание программы

1) Соколов Александр Владимирович
2) 2 Семестр 2025-2026 года обучения на бакалавриат
3) Программа создана как ВКР по бакалавриату. Основная цель программы показать полученные навыке на примере работы с информацией о раке лёгких. На основе собранной статистики требуется предсказать некоторые параметры по раку, такие как: вероятность наличия рака (основное), еги вид и мутацию, а также выживаемость. Основная цель (по предсказаниям) достигнута, дополнительные только частично.
4) Код загружен со всем зависимостями. Что возможно требуется: создать ключ для работы с API kaggle, создать MySQL БД на основе кода для MySQL и поменять глобальные данные (теже пути) в Global_data.py
5) Программа спокойно запускается при зрагрузке, но часть функционала не будет работать. Для исправления проблеммы выполните пункт 4 (Создание ключа kaggle, БД MySQL, правка файла Global_data.py) [В идеале надо было положить в контейнер, но тогда это не требовалось]
6) Проект в достаточной мере сложен для ВКР, что бы показать приобретёные навыки. Среди улучшений можно отметить: иные источники загрузки/выгрузки данных, доработать нейронные сети, почистить данные (некоторые исходные параметры сильно косвены для рака лёгких, хоть всё ещё актуальны), доработать GUI, добавить объём и разнообразие данных, расмотреть вариант распаралеливания некоторых процессов (сильно ограниченно в текущем варианте так как исходная программа сторилась исходя из 1 потока), положить программу в контейнер, добавить защиту (не изучал защиту, несчитая авторизации), и может ещё что-то можно добавить.
